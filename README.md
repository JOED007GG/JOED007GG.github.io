# Joed Adauto — Site Profissional & Currículo de TI

Site pessoal profissional desenvolvido em **HTML5**, **CSS3** e **JavaScript** puro no modelo **Bento Grid**, acompanhado de uma página de currículo integrada no padrão **Jake's Resume (100% ATS)**.

## Recursos

- **Layout Bento Grid Profissional:** Visual limpo, responsivo e sóbrio voltado para recrutadores e oportunidades em Tecnologia da Informação.
- **Tema Claro / Escuro:** Alternância instantânea salva em `localStorage`.
- **Bilíngue (`PT` / `EN`):** Tradução completa do site e da página de currículo.
- **Currículo Integrado (`curriculo.html`):** Padrão Jake's Resume em 1 página, pronto para impressão/PDF e com botão de download direto do arquivo `assets/Curriculo_Joed_Adauto_TI.pdf`.

## Estrutura

```text
site-profissional/
├── index.html                           # Página principal (Bento Grid)
├── curriculo.html                       # Currículo web padrão Jake's Resume (ATS)
├── style.css                            # Estilos do site e folha de impressão do currículo
├── script.js                            # Idioma PT/EN, tema Claro/Escuro e interações
├── README.md
└── assets/
    ├── joed-perfil.jpeg                 # Foto de perfil profissional
    └── Curriculo_Joed_Adauto_TI.pdf     # Currículo pronto em PDF
```

## Como usar

1. Abra `index.html` no navegador para visualizar o site.
2. Clique em **Ver Currículo Online** para visualizar ou imprimir o currículo em PT ou EN, ou em **Baixar Currículo (PDF)**.
3. Para publicar no GitHub Pages (`JOED007GG.github.io`), basta enviar os arquivos desta pasta para o repositório principal.
